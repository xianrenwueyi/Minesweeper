扫雷需要通过本地服务器访问

你可能直接双击打开了 index.html。浏览器会以 file:// 协议加载它， 而该协议的 origin 是 null，CORS 策略会阻止 ES 模块与 TypeScript 源码加载， 因此界面无法渲染。

请任选一种方式启动后访问给出的地址：

  • npm run dev → 打开 http://127.0.0.1:5173/
  • npm run build 然后 npm run preview → 打开 http://127.0.0.1:4173/

若已通过服务器访问却看到本提示，请打开浏览器控制台查看具体错误。
